\begin{abstract}
\noindent
This document provides a comprehensive technical specification for the \texttt{pygnss\_rt} Python package, a production-grade framework for Real-Time Precise Point Positioning with Ambiguity Resolution (PPP-AR). The system integrates with the Bernese GNSS Software v5.4 for core geodetic computations while providing a sophisticated Python orchestration layer for data management, product acquisition, and operational automation.

\vspace{0.5cm}
\noindent
\textbf{Key Features:}
\begin{itemize}[noitemsep,topsep=0pt]
    \item Multi-GNSS support: GPS (G) + GLONASS (R) + Galileo (E) triple-constellation
    \item VMF3 Vienna Mapping Functions for tropospheric modeling
    \item CODE OSB (Observable-Specific Signal Biases) for phase bias consistency
    \item LAMBDA-based integer ambiguity resolution
    \item Automated product downloads from CDDIS, CODE, IGN
    \item ZTD to IWV conversion for meteorological applications
    \item Five international station networks (IGS, EUREF, GB, RGP, Supersites)
\end{itemize}

\vspace{0.5cm}
\noindent
\textbf{GitHub Repository:} \url{https://github.com/georgisalene/pygnss_rt}

\vspace{0.5cm}
\noindent
This document describes the system architecture, mathematical formulations, processing workflows, and configuration options.
\end{abstract}

\chapter{ZTD to IWV Conversion}

\section{Physical Background}

The ZTD to IWV conversion implements the Bevis (1992, 1994) formulation for deriving Integrated Water Vapor from GNSS-estimated Zenith Tropospheric Delay.

\subsection{Mathematical Formulation}

The Zenith Total Delay (ZTD) is decomposed into hydrostatic and wet components:
\begin{equation}
\ztd = \zhd + \zwd
\end{equation}

The Zenith Hydrostatic Delay is computed using Saastamoinen (1972):
\begin{equation}
\zhd = \frac{0.0022768 \cdot P_s}{1 - 0.00266 \cos(2\phi) - 0.00028 H}
\end{equation}

The IWV is then derived from ZWD using:
\begin{equation}
\iwv = \frac{10^6 \cdot \zwd}{\rho_w \cdot R_v \cdot (k_2' + k_3/T_m)}
\end{equation}

where $T_m$ is the mean atmospheric temperature estimated from surface temperature using the Bevis empirical formula:
\begin{equation}
T_m = 70.2 + 0.72 \cdot T_s
\end{equation}

\chapter{Mathematical Foundations}

\section{PPP-AR Observation Model}

The ionosphere-free linear combination for dual-frequency observations:

\begin{equation}
L_{IF} = \frac{f_1^2 L_1 - f_2^2 L_2}{f_1^2 - f_2^2}
\end{equation}

\begin{equation}
P_{IF} = \frac{f_1^2 P_1 - f_2^2 P_2}{f_1^2 - f_2^2}
\end{equation}

\section{Kalman Filter State Vector}

The PPP-AR state vector contains:

\begin{equation}
\vecbold{x} = \begin{bmatrix}
\vecbold{r} \\
\delta t_r \\
\ztd \\
G_N, G_E \\
\vecbold{N}
\end{bmatrix}
\end{equation}

where:
\begin{itemize}
    \item $\vecbold{r}$: Position coordinates (X, Y, Z)
    \item $\delta t_r$: Receiver clock offset
    \item $\ztd$: Zenith Tropospheric Delay
    \item $G_N, G_E$: Tropospheric gradients (North, East)
    \item $\vecbold{N}$: Carrier phase ambiguities
\end{itemize}

\section{LAMBDA Ambiguity Resolution}

The integer ambiguity search minimizes:

\begin{equation}
\|\hat{\vecbold{a}} - \vecbold{a}\|_{\mat{Q}_{\hat{a}}}^2 = (\hat{\vecbold{a}} - \vecbold{a})^T \mat{Q}_{\hat{a}}^{-1} (\hat{\vecbold{a}} - \vecbold{a})
\end{equation}

The ratio test validates the solution:

\begin{equation}
R = \frac{\|\hat{\vecbold{a}} - \vecbold{a}_2\|^2}{\|\hat{\vecbold{a}} - \vecbold{a}_1\|^2} > R_{threshold}
\end{equation}

\section{VMF3 Mapping Functions}

The Vienna Mapping Functions VMF3 compute slant delays:

\begin{equation}
m_h(e) = \frac{1 + \frac{a_h}{1 + \frac{b_h}{1 + c_h}}}{\sin e + \frac{a_h}{\sin e + \frac{b_h}{\sin e + c_h}}}
\end{equation}

\begin{equation}
m_w(e) = \frac{1 + \frac{a_w}{1 + \frac{b_w}{1 + c_w}}}{\sin e + \frac{a_w}{\sin e + \frac{b_w}{\sin e + c_w}}}
\end{equation}
